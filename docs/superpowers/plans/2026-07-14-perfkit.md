# Perfkit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a reusable `benchmarking/perfkit` tool that can run Substrate lifecycle performance tests, retain raw data, and generate a standard HTML report.

**Architecture:** Keep cluster-dependent execution in a CLI package and pure data aggregation/report generation in testable internal packages. Reuse `internal/ateclient` for ACK/Substrate runs; keep report generation dependency-free with static HTML/SVG output.

**Tech Stack:** Go, `internal/ateclient`, `pkg/proto/ateapipb`, standard library JSON/CSV/HTML, existing root Go module.
